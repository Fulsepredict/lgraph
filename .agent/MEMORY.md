# 🧠 Память проекта: Lgraph (Architecture, Contract & Context Intelligence)

**Дата последнего обновления:** 2026-11-11
**Версия:** `v2.4.1` | **Правил-предохранителей (G):** `15` (разборы инцидентов — в `.agent/MEMORY_ARCHIVE.md`)

## 📋 Паспорт проекта
- **Назначение:** локальная платформа визуализации архитектуры (`C2..C4`), сшивки межъязыковых мостов (`BridgeLinker`), машинно-проверяемых правил (`GuardrailEngine`) и сжатия контекста для AI-агентов (`MCP`).
- **Сетевая изоляция:** демон FastAPI работает строго на `127.0.0.1:8765` с заголовком `X-Lgraph-Token`, dev-сервер Vite — на `127.0.0.1:5179`.
- **Дизайн-код и запуск:** Windows 10/11 / Linux / macOS, графитовая палитра (`#0E0E10` / `#141417`), фирменный рубиновый знак `logo.png` / `logo.ico`; быстрый старт через `START_APP.bat`, ярлык Рабочего стола или консольную команду `lgraph .`.

## 🛡️ ПРАВИЛА-ПРЕДОХРАНИТЕЛИ (Guardrails)

- **G-01 (Изоляция периметра):** Никаких правок вне целевой директории без явного согласия пользователя; служебная база и токен хранятся строго в `.lgraph_runtime/` вне Git.
- **G-02 (План до кода):** На изменения `>= 2` модулей сначала составляется `Implementation Plan` с точным списком команд проверки.
- **G-03 (Анти-монолит `<= 350` строк):** Ни один продуктовый файл `.py`, `.ts`, `.tsx`, `.cjs` не превышает `350` строк (`GR-LGRAPH-SIZE`).
- **G-04 (Изолированные тесты и честные SLO):** Все автотесты работают строго в `tempfile.TemporaryDirectory()`, не задевая рабочую базу `.lgraph_runtime`.
- **G-05 (Безопасность локального API и комментариев):** Демон слушает только `127.0.0.1` + `X-Lgraph-Token`; чужие докстринги всегда оборачиваются в `<untrusted_code_doc>`.
- **G-06 (Составной первичный ключ рёбер `RC-01`):** Первичный ключ таблицы `edges` обязан включать `evidence`, чтобы параллельные каналы/маршруты между двумя файлами не затирали друг друга.
- **G-07 (Точные сигнатуры пакетов `RC-02`):** В Python SDK `mcp` v2 модели `InitializeResult` и `ToolAnnotations` импортируются из `mcp_types` со `snake_case`-полями (`read_only_hint`).
- **G-08 (Единое поколение C ABI `tree-sitter` `RC-03`):** Все пакеты `tree-sitter*` в `requirements.txt` фиксируются внутри `<0.25.0`, а экземпляры `Parser` вызываются под `threading.Lock()`.
- **G-09 (Сброс `ELECTRON_RUN_AS_NODE` и пропуск комментариев `RC-04`):** Во всех лаунчерах `electron.exe` очищать `set ELECTRON_RUN_AS_NODE=`, а в `ast_forbidden_regex` пропускать строки комментариев.
- **G-10 (Фильтрация визуальных рёбер `RC-05`):** Графовые предикаты, `PageRank` и обход соседей обязаны игнорировать синтетические рёбра `c4_rollup` и `CONTAINS`.
- **G-11 (Двойной барьер маскировки секретов `RC-06`):** `redact_inline_secrets(...)` применяется к `summary_ru`, `signature` и `evidence` как в парсерах AST, так и централизованно в `GraphRepository.save_full_index_atomic`.
- **G-12 (Автономность `MCP` без `cwd` `RC-07`):** Точка входа `run_mcp_server.py` сама выставляет `sys.path`, пишет логи строго в `sys.stderr`, проверяет `is_project_disk_dirty` перед ответом и отклоняет пустой фильтр `only_paths` предупреждением `WARNING: NO FILES MATCHED FILTER`.
- **G-13 (Гигиена открытого кода):** В коммиты репозитория запрещено включать личные пути профиля ОС (`%USERPROFILE%\...`) и названия закрытых внешних проектов — использовать маркеры `<PATH_TO_LGRAPH>` и скрипт `scripts/install_antigravity_plugin.py`.
- **G-14 (Безопасность оболочки Windows, PowerShell UTF-8 и in-place плагины `RC-08`):** В `lgraph-editor:open-file` проверять `fs.realpathSync.native` и вызывать только `shell.showItemInFolder`; пути и текст в PowerShell передавать через `env` при `[Console]::OutputEncoding = UTF8`, а папки плагинов обновлять in-place без `shutil.rmtree` на корневой папке (`WinError 32` от watcher IDE).
- **G-15 (Межпроцессный `BEGIN IMMEDIATE`, `Fail-Closed` конфиг и чистота `.bat` `RC-09`):** Запись в SQLite WAL всегда открывать через `BEGIN IMMEDIATE` до чтения ревизии; поломка `lgraph.yaml` обязана возвращать ошибку вместо сброса правил в `[]`;
  `.bat`-лаунчеры держать в 7-bit ASCII с `CRLF`; в `MCP` v2 бросать `ToolError`.
