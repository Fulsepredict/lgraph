# Independent Red-Team Auditor (`v2.0.0`)

Универсальный глобальный плагин **Независимого Технического Аудитора с чистым контекстом** (`Zero-Context Red-Team Subagent`) для всех проектов в среде **Google Antigravity**.

## Что даёт во всех ваших проектах
- **Свежий взгляд без «замыливания»:** запускает изолированного Read-Only субагента (`EnableWriteTools: false`, `EnableMCPTools: true`) с `0` токенов истории переписки.
- **Два режима проверки:**
  1. `Cold Plan Audit` — проверка архитектурного плана (`Implementation Plan`) *до* написания сложного кода;
  2. `Cold Code Audit` — безжалостная проверка написанного кода, контрактов и честности тестов *перед* сдачей задачи.
- **Синергия с `Lgraph` и автономный резерв:** если включён MCP-сервер `lgraph`, аудитор первым делом сам проверяет весь радиус зацепления через `simulate_change_impact` и `verify_architecture_rules` (не веря списку файлов от разработчика на слово). Если `lgraph` отключён — аудитор работает автономно через поиск по коду.
- **Глубокие чек-листы по стекам (`references/stack_checklists.md`):** Python/FastAPI/Asyncio, SQLite WAL/SQLAlchemy, Electron/IPC/React/TS, Безопасность периметра/DPAPI/ACL, Сеть/Прокси/Протоколы.
